📍 闭环流程时间线
Step 1: 添加记忆 (memory add)
使用 addMemory API 添加新的记忆到向量数据库
Step 2: 搜索记忆 (memory search)
使用语义搜索从向量数据库检索相关记忆
Step 3: 列出记忆 (memory list)
列出当前项目的所有记忆
Step 4: Session Idle Writeback
session.idle 事件触发 checklist 写入记忆
+ Step 1: 添加记忆
🔍 Step 2: 搜索记忆
📋 Step 3: 列出记忆
🔄 Step 4: Session Idle Writeback

当会话空闲时，系统自动生成 checklist 并写入记忆。这是 completion-gate 机制的核心部分。

📝 API 调用示例
// 1. 添加记忆 const addRes = await memoryClient.addMemory( "这是一个重要的学习笔记", "project/my-project", { type: "learning", tags: ["react", "hooks"] } ); // 2. 搜索记忆 const searchRes = await memoryClient.searchMemories( "react hooks best practices", "project/my-project", "project" ); // 3. 列出记忆 const listRes = await memoryClient.listMemories( "project/my-project", 20, "project" ); // 4. session.idle writeback (自动触发) // 当 session.idle 事件触发时，系统自动调用: await writeCompletionChecklistMemories({ task: sanitizedTask, sessionID: sessionID, promptId: promptId, containerTag: tags.project.tag, checklist: checklistResult.checklist, memoryRefs: checklistResult.memoryRefs, evidence: executionEvidence });
